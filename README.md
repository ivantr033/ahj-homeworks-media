## 🛠️ Архитектура проекта и Спецификация Нативных Web API

В рамках данного домашнего задания реализовано мультимедийное приложение "Timeline" — интерактивная лента публикаций, объединяющая работу с текстовыми постами, аудио- и видеозаписями в привязке к географическим координатам пользователя.

### 🧭 Наземный комплекс и Спецификация модулей:

1. **Geolocation API (Контур геолокации):** При отправке любого поста приложение запрашивает точные координаты через `navigator.geolocation.getCurrentPosition`. В случае блокировки доступа или отсутствия GPS, открывается кастомное модальное окно для ручного ввода широты и долготы.
2. **MediaRecorder API (Аудио и Видео записи * Задачи со звездочкой):** 
   * Интерфейс полностью адаптирован под динамическое переключение: при нажатии на микрофон или камеру, стандартная панель скрывается, уступая место блоку записи с **живым таймером** (`00:00`), кнопками сохранения (✓) и отмены (✕).
   * При записи видео активируется всплывающий элемент живого превью. Видеопоток транслируется со встроенным атрибутом `muted` для предотвращения эффекта акустической петли (эха).
   * Бинарные потоки (*chunks*) упаковываются в `Blob` и воспроизводятся через нативные теги HTML5 `<audio>` и `<video>`.
3. **Jest Unit Tests (100% Тестовое покрытие):** Написаны автоматические тесты для функции `parseCoordinates.js`, отвечающей за валидацию ручного ввода. Тесты со 100% точностью покрывают:
   * Координаты с пробелом (`51.50851, -0.12572`)
   * Координаты без пробела (`51.50851,-0.12572`)
   * Координаты в квадратных скобках (`[51.50851, -0.12572]`)
   * Исключения при пустом вводе и значениях, выходящих за рамки диапазонов Земли.

npm start
